## 需求

一个命令行程序，管理你的待办事项。

### 必须有的功能

| # | 功能 | 说明 |
|---|---|---|
| 1 | **添加任务** | 输入一段文字，加进清单 |
| 2 | **查看清单** | 打印所有任务，带序号和状态 |
| 3 | **标记完成** | 按序号把某条标记为完成 |
| 4 | **删除任务** | 按序号删掉某条 |
| 5 | **按状态筛选** | 只看未完成 / 只看已完成 |
| 6 | **持久化** | 数据存 JSON 文件，关掉再打开还在 |

### 界面参考（具体你自己定）

```
待办清单
  1. [ ] 买牛奶
  2. [x] 交作业
  3. [ ] 打电话

> add 写周报
已添加：写周报

> done 1
已完成：买牛奶

> list undone
  1. [ ] 打电话
  2. [ ] 写周报

> quit
```

### 技术要求

- **纯 Python**，不用第三方库
- **拆成多个函数**，不要全堆在 `main()` 里
- 数据文件命名 `tasks.json`
